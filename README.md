# AsmaCare
Fictional healthcare portal used as a DevOps learning workload. All patient/health-card data is synthetic.

Stack: React/Vite frontend, Spring Boot API, MySQL, Docker Compose.

Run:
```bash
docker compose up --build
```
Frontend: http://localhost:5173
Backend health: http://localhost:8080/actuator/health

Stage 1 only. Kubernetes, Helm, GitHub Actions, observability, GitOps, Terraform/AWS and AIOps will be added step by step.
